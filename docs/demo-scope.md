# Задачи демонстрационной версии

План из TASKS_demo.docx сверён с локальным проектом NEIROSLOP BURMALDA. Temple of Gold и Neon Nights выполняют пункты про Temple Gold и Neon City. Они используют прежние идентификаторы, чтобы существующие ссылки и история продолжали работать.

| Этап | Что есть в проекте |
| --- | --- |
| 1. Архитектура | React/Vite, FastAPI и PostgreSQL, структура модулей, настройки среды и инструкции запуска. Правила работы с ветками описаны в README и применяются владельцем репозиториев. |
| 2. Интерфейс | Каталог, категории, поиск, сортировка, избранное, маршруты игр, адаптивные экраны и профиль. |
| 3. Игровой интерфейс | Анимация и последовательная остановка барабанов, ставка, выделение выигрыша, отдельная анимация крупного выигрыша и обработка ошибок. |
| 4. Игры | Добавлены Cosmic Rush, Candy Riot и Dragon Grove. У них свои символы, таблицы выплат и бонусные вращения. Всего в каталоге 12 игр. |
| 5. Кошелёк | Стартовый баланс, ставки, выигрыши, ежедневный подарок и четыре достижения. Награды доступны в My account → Rewards, журнал операций — в My account → Activity. |
| 6. API | Каталог, профиль, атомарный запуск и расчёт раунда, чтение результата, история, бонусы, достижения и журнал кошелька. |
| 7. PostgreSQL | Транзакции и блокировка строки игрока, индексы истории, ревизии схемы с поддержкой существующей базы. |
| 8. Пользователи | Гостевые сессии, регистрация, вход и выход, хеширование паролей, 2FA, повтор запросов без повторного списания, ограничение новых раундов на кошелёк. |
| 9. Проверки | Тесты движка и API, проверка сохранения после перезапуска, отдельная проверка конкурентных запросов на PostgreSQL и сквозной сценарий в контейнерном CI. |
| 10. Эксплуатация | Docker, Compose, сборка и CI/CD, журналирование отклонённых игровых запросов, инструкция резервного копирования и игровая справка. |

## API демонстрационной версии

Swagger UI доступен на `/docs`. Для личных запросов нужна сессионная cookie из `GET /api/session`. Клиент передаёт ожидаемый ID кошелька в `X-Lounge-Player`; при смене аккаунта сервер отклоняет запрос со статусом 409. Ошибки возвращаются в поле `error`.

| Маршрут | Назначение |
| --- | --- |
| `GET /api/games` | Каталог. Для новых автоматов `paytable` содержит множители за 3, 4 и 5 совпадений. |
| `POST /api/spin` | Раунд слота. Принимает `game`, целую `bet` от 1 до 10 000 и UUID `requestId`. Возвращает сохранённый результат с серверным `id`. |
| `GET /api/rounds/{id}` | Результат раунда текущего кошелька. |
| `GET /api/history` | Последние 30 раундов кошелька. |
| `GET /api/rewards` | Срок следующего ежедневного подарка и прогресс достижений. |
| `POST /api/bonus` | Ежедневный подарок. Пустое JSON-тело. |
| `POST /api/rewards/{id}/claim` | Начисляет награду и возвращает обновлённый профиль. Принимает пустое JSON-тело. Повторное получение или недостигнутая цель возвращают 409. |
| `GET /api/wallet/transactions` | Последние 50 операций, сумма каждой операции, остаток после неё и ID связанного раунда. |

На один кошелёк допускается до 120 новых проведённых раундов в минутном окне, общем для слотов и рулетки. При 429 заголовок `Retry-After` показывает время ожидания в секундах. Сохранённый результат можно повторно получить с тем же `requestId`.

## Обложки и символы

На широких экранах оригинальные горизонтальные обложки сохраняют детализацию в верхней части игрового экрана и плавно переходят в вертикальный фон. Для корпусов встроенный ImageGen создал прозрачные рамки `{cosmic,candy,dragon}-cabinet-frame.png`: орбитальное оборудование из титана и светящихся трубок, карамельные колонны с глазурью и резной дуб с мхом, бронзовыми драконами и изумрудами.

Cosmic Rush, Candy Riot и Dragon Grove используют поле 5 × 6 с десятью линиями выплат: шесть горизонтальных и четыре фигурных. Кнопка «10 paylines» открывает схемы всех линий. После выигрыша можно выбрать схему конкретной комбинации, чтобы выделить её ячейки. Вертикальные фоны `{cosmic,candy,dragon}-stage-tall.png` расширены встроенным ImageGen из оригинальных обложек с продолжением туманности, карамельной реки и лесных корней соответственно.

Обложки и спрайты в `client/public/assets/{cosmic,candy,dragon}-{scene,symbols}.png` созданы встроенным ImageGen. Для обложек использовались три сцены: планета с кольцами в индиго-туманности, конфетный мир с леденцами и изумрудный дракон в древнем лесу. Для каждой игры отдельно создан прозрачный атлас 4 × 2 из семи тематических предметов в порядке символов движка.

## Локальная проверка

```sh
npm test
npm run build
python -m pytest backend/tests
```

Для теста конкурентных запросов задайте `TEST_POSTGRES_URL` с подключением к отдельной пустой тестовой базе. Тест создаёт в ней схему и кошелёк. Производственную базу для этой проверки не используйте.
