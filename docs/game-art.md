# Goldrush Canyon artwork and sound

Original assets generated with the built-in ImageGen tool for this project:

- `client/public/assets/goldrush-scene.png`: mine and canyon environment.
- `client/public/assets/goldrush-symbols.png`: transparent 4-column, 2-row symbol atlas.

## Scene prompt

Use case: stylized-concept. Create a premium original slot-game environment background, landscape 1536x1024. An atmospheric old gold mine in a spectacular amber canyon at dusk, carved timber entrance and metal rails receding into a warmly lit mine tunnel, loaded ore cart at lower right, nuggets, pickaxe, lanterns, ropes, weathered beams, scattered quartz crystals. Realistic detailed 3D game art, cinematic golden rim lighting, textured wood and riveted iron, deep forest teal shadows and copper-gold highlights. Wide view with quiet dark center to sit behind live HTML slot reels, detailed scenery strongest around edges and top. No slot machine, no interface, no text or lettering, no logos. Rich high-end casino game production art.

## Symbol atlas prompt

Use case: stylized-concept. Asset type: transparent game symbol sprite atlas. Exactly 4 columns by 2 rows, 8 equally sized square cells in a precise regular grid. Each object isolated, fully contained in its own square, centered with equal padding, no overlap or shadows outside cell. Transparent background. Premium realistic detailed 3D casino symbols in an original gold-mining theme. Row 1 left to right: faceted turquoise quartz cluster with gold ore base; large polished gold nugget cluster; glowing amber miner lantern in weathered brass frame; antique ore cart full of gold. Row 2 left to right: crossed steel pickaxes on a wooden medallion; ornate golden sheriff star framed in turquoise as wild symbol; antique dynamite bundle with a coiled fuse and polished brass medallion as bonus symbol; antique gold coin. Strong silhouettes, polished materials, bright studio light, grounded wood and brass, crisp detail, consistent perspective. No text, no letters, no numbers, no brand marks. All 8 cells equal, 4x2 sprite sheet, transparent background.

## Sound effects

Current audio uses the shared lounge soundtrack, individual cell-landing cues and stereo coin rain. See [audio.md](audio.md) for the current files, mixer and regeneration instructions. The earlier reel-mechanism effect is retired.

## Reference

[Bonanza by Big Time Gaming](https://www.bigtimegaming.com/games/bonanza/) was the user's reference for visual richness. Goldrush Canyon uses its own artwork, cabinet, title and fixed-payline rules. It has five reels, five paylines, up to eight winning cascades per wager and ten bonus spins for three BONUS symbols in any one cascade frame.
